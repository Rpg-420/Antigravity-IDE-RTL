# Antigravity-IDE-RTL — راست‌چین + فونت وزیرمتن برای Antigravity IDE 🚀

راست‌چین‌سازی و فونت فارسی برای **Antigravity IDE** (محیط ایجنت‌محور گوگل بر پایه VS Code) روی **ویندوز** — شامل **پنل چت ایجنت** که معمولاً از دست همه در می‌رود.

> یک کلیک: فونت فارسی در کل رابط، پاراگراف‌های فارسی راست‌چین، آیکون‌ها و کد بدون تغییر.

---

## شروع سریع

۱. ریپو را دانلود کن (Code → Download ZIP) و هرجا خواستی استخراج کن.
۲. روی **`Install-RTL.cmd`** دابل‌کلیک کن.
۳. **آنتي‌گراویتی را کامل ببند** (Task Manager را چک کن، پروسه‌های پس‌زمینه می‌مانند) **و دوباره باز کن.**

تمام. فونت فارسی UI + چت راست‌چین.

```
Antigravity-IDE-RTL/
├── Install-RTL.cmd        ← همین را دابل‌کلیک کن
├── Uninstall-RTL.cmd      ← حذف کامل
├── install.ps1            ← نصب‌کننده (-Uninstall / -PersistReboot / -FontStack)
├── fonts/Vazirmatn/       ← فونت وزیرمتن همراه ریپو (آفلاین هم کار می‌کند، لایسنس OFL)
└── docs/HOW-IT-WORKS.md   ← توضیح فنی
```

نیاز به دسترسی Administrator ندارد. چیزی کامپایل نمی‌شود. اجرای دوباره همیشه بی‌خطر است.

## چه می‌کند؟

| بخش | رفتار |
|---|---|
| **فونت** | وزیرمتن (یا فونت دلخواه تو) در کل رابط |
| **چت ایجنت** | پاراگراف/لیست/عنوان/سلول‌های فارسی راست‌چین؛ **بلوک‌های انگلیسی چپ‌چین می‌مانند** |
| **آیکون‌ها، دکمه‌ها، تولبار** | هرگز آینه نمی‌شوند (فونت آیکون codicon/seti محافظت شده) |
| **ادیتور و ترمینال** | monospace و چپ‌چین |
| **ماندگاری** | میان‌بر استارت‌آپ بعد از هر لاگین همه‌چیز را دوباره اعمال می‌کند و اگر آنتي‌گراویتی با کد قدیمی باز باشد ری‌استارتش می‌کند |
| **برگشت‌پذیری** | `Uninstall-RTL.cmd` فایل `main.js` را برمی‌گرداند و همهٔ اثرات را پاک می‌کند |

## چرا اصلاً «پچ» لازم است؟

آنتي‌گراویتی اکستنشن‌های VS Code را داخل رابط خودش لود نمی‌کند، پس یک اکستنشن معمولی نمی‌تواند ظاهر برنامه یا چت ایجنت را تغییر دهد. جزئیات کامل در **[docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md)** — خلاصه:

- برنامه با ساختار **ESM باز‌شده** (`resources/app/out/main.js`) نصب می‌شود، نه `app.asar`؛ پس اسکریپت‌های مبتنی بر asar بی‌صدا هیچ کاری نمی‌کنند.
- برنامه **single-instance** است؛ استارت دوباره به پروسهٔ موجود تحویل می‌شود، پس پچ باید ری‌استارت واقعی انجام دهد.
- چت ایجنت یک **iframe با اوریجین جدا** است که از یک سرور HTTP محلی سرو می‌شود؛ preload معمولی Electron به آن نمی‌رسد — این ابزار با `webFrameMain` در **همهٔ فریم‌ها** تزریق می‌کند.
- ویندوز فونت‌های per-user را فقط *ثبت* می‌کند؛ بدون `AddFontResource` + `WM_FONTCHANGE` کروم همیشه به Segoe UI برمی‌گردد و پچ سالم، «خراب» به نظر می‌رسد.

## سفارشی‌سازی

```powershell
# استک فونت خودت (باید روی سیستم نصب باشد)
.\install.ps1 -FontStack "'IRANSans', 'Vazirmatn', sans-serif"
```

- **فونت اضافه:** فایل‌های `.ttf` را در پوشهٔ `fonts-extra` کنار `install.ps1` یا در `D:\Font\IRANSans` بگذار — خودکار برداشته می‌شوند.
- ایران‌سنس همراه ریپو **نیست** (لایسنسش قابل بازنشر آزاد نیست). اگر داشته باشی، نصب‌کننده پیدایش می‌کند و به استک اضافه می‌کند.

## بررسی و عیب‌یابی

```powershell
# آیا پچ واقعاً لود شده؟ یک خط به ازای هر فریم:
Get-Content "$env:USERPROFILE\antigravity-ui.log" -Tail 5

# لاگ نصب‌کننده
Get-Content "$env:LOCALAPPDATA\Antigravity-RTL\installer.log" -Tail 20
```

| نشانه | راه‌حل |
|---|---|
| هیچ تغییری نیست | آنتي‌گراویتی هنوز باز بود → کامل ببند (Task Manager) و باز کن |
| چت فونت فارسی نگرفته | `Install-RTL.cmd` را دوباره اجرا کن و برنامه را کامل ری‌استارت کن |
| متن‌ها با Segoe UI رندر می‌شوند | یک بار لاگ‌آف/لاگین کن (فونت‌ها در لاگین لود می‌شوند) یا نصب‌کننده را دوباره اجرا کن |
| بعد از آپدیت آنتي‌گراویتی | `Install-RTL.cmd` را دوباره اجرا کن، یا بگذار میان‌بر استارت‌آپ در لاگین بعدی انجام دهد |
| دکمه/آیکون‌ها به‌هم‌ریخته | نسخهٔ قدیمی که RTL را سراسری اجباری می‌کرد — به نسخهٔ فعلی آپدیت کن |

## پیش‌نیازها

- ویندوز ۱۰/۱۱
- آنتي‌گراویتی در مسیر استاندارد (`%LOCALAPPDATA%\Programs\Antigravity IDE`، `…\Antigravity` یا `Program Files\Antigravity IDE`)
- PowerShell 5.1 (همراه ویندوز) — بدون admin، بدون Python، بدون Node
- اینترنت فقط برای دانلود اختیاری فونت (فونت داخل ریپوست، پس آفلاین هم کار می‌کند)
